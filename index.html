Online Cloud Edition · Zero Install

MMTools Web App (Cloud Run)

Hosted on Google Cloud with global CDN acceleration and Firebase Authentication. Ideal for pre-meet preparation, remote team managers, and pools with cellular or Wi-Fi coverage.

  • One-Click Google Drive Picker: Browse and import .mdb or JSON meet databases directly from your team's shared Google Drive.
  • Cloud-Assisted Report Rendering: Generate complete PDF report packs and Google Sheets attendance trackers in the cloud without taxing your laptop battery.
  • Live QR Code Publishing: Publish heat/lane programs to the cloud so deck officials and parents can sync immediately on their phones.
  • Permanent Cloud URL: Bookmark mmtools-app.web.app on any Mac, PC, Chromebook, or tablet.

Offline Desktop Edition · macOS & Windows

MMTools Native Desktop App

A self-contained native Tauri desktop application bundling the Python/Java MDB extraction engine and WeasyPrint PDF renderer locally—built for swim clubs where pool-deck Wi-Fi is unavailable or unreliable.

  • 100% Offline Capable: Parses .mdb Access files and renders PDF bundles locally on your machine with zero internet dependency.
  • Bundled Runtime: Ships with an embedded JVM, Jackcess/UCanAccess MDB parser, and Cairo/Pango PDF engine—nothing extra to install.
  • Direct timing file ingestion: Watch local timing directories for Colorado Time Systems (CTS) and Dolphin result files.
  • Native File Dialogs: Save ZIP report packs and .scb scoreboard start lists directly to local USB drives for the timing console.

 macOS First-Launch Authorization Instructions (Click to expand) +
Because MMTools Desktop is compiled and packaged automatically via GitHub Actions, macOS Gatekeeper may show an "unidentified developer" prompt on first launch. Authorize only MM-Tools.app using either method:
  1. System Settings → Privacy & Security: Attempt to open MM-Tools.app, click Cancel, then click Open Anyway under Privacy & Security.
  2. Terminal One-Liner: Clear the download quarantine flag for MM-Tools.app:
xattr -d com.apple.quarantine /Applications/MM-Tools.app
